## 4. Категории персональных данных

### Обрабатываемые:
- Фамилия, имя, отчество
- Адрес электронной почты
- Номер телефона
- Идентификатор Telegram
- IP-адрес
- Данные об использовании сервиса (команды, логи, метрики)
- Данные агентов (тип, версия, hostname)
- Платёжные данные (от банка-эквайрера)

### НЕ обрабатываемые:
- Биометрические данные
- Данные о расовой/национальной принадлежности
- Политические взгляды
- Религиозные убеждения
- Состояние здоровья
- Интимная жизнь

## 6. Меры защиты (ст. 19 152-ФЗ)

### Организационные:
- Назначено лицо, ответственное за обработку ПДн: Юдин А.Е.
- Разработана Политика конфиденциальности
- Опубликованы Условия использования
- Получение согласия в электронной форме (чекбокс при регистрации)
- Ограничение доступа на основе принципа минимальных привилегий

### Технические:
- Шифрование при передаче: TLS 1.3
- Шифрование при хранении: AES-256-GCM
- Хранение паролей: bcrypt (work factor ≥ 12)
- Сетевая защита: файрвол, ограничение IP
- Резервное копирование: ежедневное, шифрованное
- Мониторинг: журналирование всех действий
- E2EE: agent ↔ relay

### Физические:
- Сервер расположен в ЦОД в г. Москве (IP: 93.93.207.44)
- Доступ к серверу ограничен (SSH, ключи, без паролей)

## 8. Уровень защищённости (Постановление № 1119)

**Тип ИСПДн:** Автоматизированная, без передачи по сети ИСПДн / с передачей

**Оценка:** Уровень защищённости — **УЗ-4** (низший) или **УЗ-3**
- Количество субъектов: менее 100 000 (ожидается)
- Тип данных: общие (не специальные категории)
- Отсутствуют негативные последствия 1-2 типа

**УЗ-4** — не требует применения сертифицированных СКЗИ
**УЗ-3** — может потребоваться сертифицированные средства
