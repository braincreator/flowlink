# Положение об обработке персональных данных

## 1. Общие положения

1.1. Настоящее Положение разработано в соответствии с Федеральным законом от 27.07.2006 № 152-ФЗ «О персональных данных».

1.2. Целью настоящего Положения является определение порядка обработки персональных данных в ИСПДн FlowLink.

1.3. Оператор: ИП Юдин Александр Евгеньевич (ИНН 032628977859).

## 2. Состав ИСПДн

2.1. Информационная система персональных данных включает:
- Веб-сервер (Next.js) — сбор данных через формы
- API-сервер (Rust relay) — обработка запросов
- База данных (PostgreSQL) — хранение данных на сервере 93.93.207.44 (г. Москва)
- Telegram Bot — отправка уведомлений (трансграничная передача)

2.2. Тип ИСПДн: автоматизированная, с передачей данных по сети Интернет.

## 3. Категории обрабатываемых данных

3.1. Фамилия, имя, отчество
3.2. Адрес электронной почты
3.3. Номер телефона (опционально)
3.4. Идентификатор Telegram (опционально)
3.5. IP-адрес
3.6. Данные об использовании сервиса
3.7. Платёжные данные (через банк-эквайрер)

3.8. **Не обрабатываются:** биометрические, специальные категории (ст. 10 152-ФЗ).

## 4. Порядок получения согласия

4.1. Согласие получается в электронной форме при регистрации (ст. 9 152-ФЗ).
4.2. Пользователь отмечает чекбокс согласия с ToS и Privacy Policy.
4.3. При использовании Telegram-бота и GitHub OAuth — информирование о трансграничной передаче (ст. 12).
4.4. Отзыв согласия — через email admin@flow-masters.ru или настройки аккаунта.

## 5. Порядок хранения и защиты

5.1. Все данные хранятся на сервере в РФ (242-ФЗ).
5.2. Шифрование: TLS 1.3 (передача), AES-256-GCM (хранение).
5.3. Пароли: bcrypt (work factor ≥ 12).
5.4. Резервное копирование: ежедневное, зашифрованное.
5.5. Доступ ограничен: SSH-ключи, без паролей.

## 6. Порядок уничтожения

6.1. Команды AI-агентов — 90 дней.
6.2. Данные аккаунта — 30 дней после удаления.
6.3. Журналы аудита — срок действия договора + 3 года.
6.4. Платёжные данные — 5 лет (Налоговый кодекс).

7.2. Нарушение порядка обработки влечёт ответственность по КоАП ст. 13.11.
