## 1. Описание проекта

### 1.1. Суть проекта
FlowLink — первая в России платформа безопасности для AI-агентов, реализованная как MCP (Model Context Protocol) Gateway. Платформа перехватывает, анализирует и контролирует все команды, выполняемые AI-ассистентами (Claude, GPT, Cursor, Copilot) в реальном времени, предотвращая утечки данных, выполнение деструктивных команд и несанкционированный доступ.

### 1.2. Проблема
С массовым внедрением AI-ассистентов в разработку (GitHub Copilot, Cursor, Claude Code) возникает принципиально новый класс угроз:
- AI-агент может выполнить `rm -rf /` по указанию из вредоносного промпта
- AI может слить API-ключи и секреты в сторонний сервис
- Prompt injection может заставить агента выполнить произвольные команды
- Нет стандартных инструментов для контроля AI-агентов

Рынок AI-безопасности вырастет с $7.8 млрд (2024) до $35.5 млрд (2029) (CAGR 35.3%, MarketsandMarkets).

### 1.3. Решение
FlowLink устанавливается как прокси между AI-агентом и операционной системой:
1. **Shield Engine** — анализ каждой команды в реальном времени (pattern matching, risk scoring, policy enforcement)
2. **MCP Gateway** — нативная интеграция с Model Context Protocol (стандарт Anthropic/OpenAI)
3. **GitOps Bridge** — автоматическое обнаружение drift конфигураций, бэкап, восстановление
4. **Kubernetes Operator** — защита AI-агентов в k8s кластерах (CRD, webhook, sidecar injection)
5. **Secrets Vault** — безопасное внедрение секретов без их раскрытия агенту
6. **Compliance** — полный аудит-трейл для ФСТЭК, 152-ФЗ, 242-ФЗ

## 2. Инновационность

### 2.1. Технологическая новизна
- **MCP-native подход:** единственный gateway, реализованный на уровне протокола MCP (не просто HTTP прокси)
- **Real-time policy engine:** анализ команд за <5ms (Rust), нулевая задержка для пользователя
- **E2EE agent-relay:** end-to-end шифрование между агентом и сервером
- **Open-core архитектура:** 7 публичных библиотек (Rust crates), 6 приватных модулей

### 2.2. Полная функциональность (18 модулей)

**Безопасность (Security):**
1. **Shield Engine** — real-time анализ и блокировка команд (<5ms, Rust)
2. **Policy Engine** — настраиваемые политики allow/deny/approve с regex и risk scoring
3. **Pattern Learning** — ML-based обучение паттернов использования (адаптивные политики)
4. **Forensics** — криминалистический анализ инцидентов (timeline, evidence chain)
5. **E2EE** — end-to-end шифрование agent ↔ relay
6. **Approval Workflow** — двухфакторное подтверждение опасных команд
7. **Zero Trust Secrets** — внедрение секретов без их раскрытия AI-агенту

**Наблюдаемость (Observability):**
8. **Audit Trail** — полный лог всех команд (who/what/when/result/risk)
9. **Command History** — поиск, фильтрация, dry-run против политик
10. **Agent Health Monitoring** — CPU/RAM/Disk/uptime в реальном времени
11. **SIEM Export** — интеграция с Splunk, ELK, QRadar (CEF/JSON)
12. **Service Catalog** — реестр подключённых агентов и их capabilities
13. **Infrastructure Map** — визуальная карта agent ↔ relay ↔ services
14. **AI Ops Dashboard** — метрики AI-операций, аномалии, тренды

**Управление (Control):**
15. **RBAC** — role-based access control с кастомными ролями
16. **GitOps Bridge** — drift detection, auto-backup, restore, ServerGuard
17. **Kubernetes Operator** — CRD, webhook, sidecar injection
18. **Webhooks** — события в real-time (блокировки, подключения, алерты)

**Enterprise:**
- **SSO/SAML** — интеграция с корпоративными IdP
- **On-Premise** — развёртывание в закрытом контуре
- **Compliance** — генерация отчётов ФСТЭК/152-ФЗ
- **Telegram Bot** — уведомления и управление через Telegram
- **Interactive Sessions** — WebSocket чат с агентами через dashboard
